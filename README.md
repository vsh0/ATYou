ATYou website project

Project description: ATYou was created to help first year students entering third-level education. The website contains tips, advice, and resources to help first-year ATU students settle in, find their way, and thrive. It's design is colorful and inviting. Some aspects of the site are only placeholders such as the news and blog sections. The website is best viewed on destop. The website was originally a group project, credits to Niabh Lynch for creating the logo, map assets, and text for certain pages.

Technologies used: HTML, CSS, JS

Setup instructions: Open the website https://vsh0.github.io/ATYou/index.html

Usage: Watch ATYOU Demmonstration.mp4
